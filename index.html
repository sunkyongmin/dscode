원내 약품 사전

AI가 처방 약을 잘못 짐작하지 않도록 상품명의 성분·분류를 알려 줍니다. 한 줄에 하나씩 "상품명 = 성분, 분류". 여기 없는 약은 AI가 성분을 추정하지 않고 "성분 확인 필요"로만 표시합니다. 중계 서버에 식약처 인증키(MFDS_KEY)를 등록해 두면, 사전에 없는 약을 상병 추천 때 식약처 허가정보에서 자동으로 찾아 함께 보내고 "사전에 추가" 버튼을 띄웁니다.

탭별 설명

    
진료

    
추천 — ① 템플릿 복사 → EMR에 붙여넣기 ② 기록을 마친 뒤 EMR 기록 전체를 붙여넣기 ③ 상병 추천(Ctrl+Enter). AI가 주진단·부진단·R/O 상병을 이유와 함께 제시하고, 코드표와 병원 규칙으로 검증해 문제가 있으면 한 번 자동 보정합니다. 결과 맨 위의 Imp) 문구 복사로 EMR Imp) 아래에 붙여넣습니다. 전송 전 6자리 이상 숫자·전화·주민번호는 자동으로 가립니다. 템플릿은 "템플릿 관리"에서 과장별로 추가·수정합니다.

    
검색 — 추정진단명, 응급실 약어(AGE, LBP, ICH…), 한글, 영문, 코드 앞자리 어느 것으로든 찾습니다. 코드 클릭 = 복사. 빨간 표시는 사용불가·불완전코드(청구 거절), 노란 표시는 주상병 지양. "메모"로 "심사팀 선호" 같은 병원 고유 정보를 남길 수 있습니다. 검색창이 비어 있으면 최근 복사한 코드가 보입니다.

    
점검 — 약·검사·처치와 입력한 상병코드를 적으면 병원 규칙에 비춰 빠진 상병(예: Gaster → K219 없음), 쓰면 안 되는 코드(예: R53), 기록 보완(예: suture 시 cm 기재)을 알려 줍니다. AI 없이 즉시 동작합니다.

    
심사 관리

    
요청기록 — 심사팀이 상병 수정을 요청할 때마다 상황·원래 코드·요청 코드·사유를 적습니다. 환자 식별정보는 적지 마세요. "규칙화"를 누르면 규칙 입력 칸에 자동으로 채워집니다.

    
규칙 — 점검·추천이 사용하는 병원 규칙 목록. 종류는 세 가지: 처방→필요 상병, 코드→사용불가·교체, 기록 작성 유의사항. 조건은 쉼표로 여러 개(모두 만족), 같은 뜻은 |로 묶습니다(예: gaster|가스터). 여기 넣은 규칙은 AI 추천에도 자동 반영됩니다.

    
분석 — 요청기록이 쌓이면 반복 패턴, 자주 나오는 상황, 월별 건수를 보여 줍니다. 두 번 이상 반복됐는데 규칙이 없으면 "규칙화 권장"이 표시됩니다.

    
연구 — IRB 승인 후 켜는 연구용 사용 기록. 추천 상병·경고·최종 Imp) 상병·소요시간을 원문 없이 남기고, 사용 로그·괴리 사례·심사팀 요청기록을 CSV로 내보냅니다. 기준-임상 괴리 사례는 요청기록 탭 아래쪽에서 적습니다.

    
참고·설정

    
기준 — 의무기록실 안내문 원문. 읽기 전용입니다.

    
설정 — API 키·모델·연결 테스트, 코드표 상태, 규칙·기록 백업(내보내기/가져오기), 기본 규칙 초기화.



  

    
"삭감 안 되는 상병"인지 어떻게 판단하나

    
삭감 여부를 100% 알려 주는 공식 자료는 없습니다. 이 앱은 세 겹으로 확인하고, 추천 결과의 각 상병 아래에 그 결과를 태그로 보여 줍니다.

    
    
      
  1. 코드표 — 심평원 상병마스터 속성. 불완전코드(세분류가 있는 상위코드)와 주상병불가 코드는 확실히 거절되므로 여기서 걸러집니다.
    2. 
      
  2. 병원규칙 — 의무기록실·심사팀이 알려 준 동신병원 기준(R53 불가, Qupron+A099 불가 등). 규칙 탭에서 늘려 갑니다.
    3. 
      
  3. 급여기준 — 심평원 「요양급여의 적용기준 및 방법에 관한 세부사항」 2026년 7월판 원문에서 응급실 관련 항목을 규칙으로 넣었습니다. 행위 11개(트로포닌·CK-MB·마이오글로빈, BNP, 프로칼시토닌, D-dimer, 인플루엔자·코로나 동시 신속검사, 응급초음파 나952, Brain MRI, 창상봉합, 6시간 내 재방문), 약제 13개(PPI 주사, 5-HT3 항구토제, 정장생균제, 간장용제, oseltamivir, 알부민, flumazenil, epinephrine 자가주사, ambroxol 주사, 진해거담제, 항혈소판제, somatostatin, etomidate). 규칙 설명에 책자 쪽수와 고시 번호가 있어 원문과 대조할 수 있습니다. 그 밖의 처방은 "미확인"으로 표시됩니다.
    4. 
    

    
즉, 코드표 ✔ + 병원규칙 ✔이면 "알려진 삭감 사유는 없음"이지 "삭감 안 됨 보장"은 아닙니다.
