상병코드 검색

처방·검사와 입력한 상병을 병원 기준으로 점검

약 이름, 검사, 처치, 상병코드를 줄바꿈이나 쉼표로 구분해서 입력.

의무기록실 안내 원문 — 응급실 의무기록 작성관리 (TEL 2225)

보험심사 기준의 참고용 원문입니다. 점검·추천 기능은 이 내용을 규칙 탭의 규칙으로 옮겨 사용합니다.

[작성관리 (1)]
1. 주진단으로 V, W, X, Y 코드 사용 불가
   : 외인에 대한 특정 기타결과를 나타내는 S, T 코드를 주진단으로 입력
   예) Rt. forearm 집에서 키우는 개에 물려 내원
       주) S508 아래팔의 기타 표재성 손상
       부) W540 개에 물림 또는 부딪힘, 주택
   cf. T141(동물물림 NOS) 코드는 사용 불가

2. 진단으로 대체할 수 있는 특정 R코드는 주진단에 지양
   지양할 R코드: R51(두통), R42(어지럼증 및 어지럼), R99(사망), R54(노쇠), R413(기타 기억상실) 등
   R53(전신쇠약)은 아예 사용 불가한 코드 → 약제 or PHx로 코드 부여 (예: F480 신경무력증)

3. Qupron Tab. 사용 시 A099(상세불명 기원의 위장염 및 결장염) 사용 불가
   → A049(상세불명의 세균성 장감염)으로 입력

4. J00, J060, J069 → J40(급성인지 만성인지 명시되지 않은 기관지염)으로 입력
   J209는 15세 미만에서의 기관지염 → J40으로 입력

5. 인수인계 또는 재내원의 경우 CC, PI, IMP, Onset 기재
   인수인계: cc) pi) onset) imp) 주)  /  재내원: cc) pi) onset) imp) 주)

6. 발병시간 기입 시 2일 전까지는 '시간' 입력 (NEDIS 전송 시 필요)  예) 2일전 7시

7. 경과기록에 작성하는 상병과 진단명 일치. 진단명 문구에 (주) / (부) 문구 작성

8. T140-4(타박상 NOS) 코드 사용 불가 → S코드 중 해당하는 타박상 코드 입력

[작성관리 (2)]
1. 약제/주사별 상병 매칭
   1) Nebulizer → J459(상세불명의 천식)
   2) URSA → K769(상세불명의 간질환)
   3) Restam/Pamagen → K297(상세불명의 위염)
   4) Gaster inj → K219(식도염을 동반하지 않은 위-식도 역류병)
   5) Gaster inj + Pamagen → K219
   6) Gaster inj + Restam → K219 + K297
   7) Macperan → R111(구역) R112(구토) R113(구역을 동반한 구토)

2. 검사별 상병 매칭
   1) Pro-BNP → r/o I509(상세불명의 심부전)
   2) D-Dimer → r/o I7439(기타 및 상세불명 색전증 및 혈전증)
   3) CK-MB → Z035(기타 의심되는 심혈관 질환의 관찰) — 주진단 사용 불가
   4) Hemoglobin A1C → R730(이상포도당내성검사) — 당뇨병 코드(E10_~E14_) 범주의 어떤 코드와도 동시 분류 불가
   5) Abd, Chest CT 동시촬영 (예: 장염으로 방문했을 때 Chest CT 촬영) → 경과기록지에 소견 작성, 진단명 각각 부여
   6) Abd CT의 경우 A099(상세불명 기원의 위장염 및 결장염) 코드로는 수가 인정되지 않음 → 보완상병 입력
   7) 외상으로 S010(두피의 열린상처) 있으면서 Brain CT 촬영하는 경우 → S0600(열린 두개내상처가 없는 진탕) 코드 같이 입력

3. 기타
   1) R33(소변정체) → R391(기타 배뇨곤란)
   2) 사후피임약 처방 → Z308(기타 피임관리) or Z309(상세불명의 피임관리)
   3) Suture 시 경과기록에 wound 'cm' 기재

심사팀 수정 요청 기록

심사팀이 물어보러 올 때마다 적어 두면 분석 탭에서 반복 패턴이 보이고, 규칙으로 바로 바꿀 수 있습니다. 환자 식별정보는 적지 마세요.

규칙 추가

코드 조건은 코드 그대로(R53), 앞자리만 맞추려면 별표(E1*, W*)

AI 연결 (Claude API)

API 키는 이 브라우저에만 저장되고 Anthropic API 호출에만 쓰입니다. 병원 PC에서 api.anthropic.com 접속이 막혀 있으면 아래 연결 테스트가 실패합니다.

상병코드표

같은 폴더의 kcd.json(심평원 상병마스터 변환본, 형식: [코드, 한글명, 영문명, 속성, 동의어])을 자동으로 읽습니다. 속성: I 불완전코드, P 주상병불가, F/M 성별, a하한-상한 연령. 또는 아래에서 JSON/CSV(코드,한글명,영문명) 파일을 직접 불러올 수 있습니다(이번 세션만 유지).

백업·복원 (규칙·요청기록·코드 메모)

이 앱은 무엇인가

응급실에서 상병코드를 고를 때 보험심사에서 삭감되지 않을 코드를 빨리 찾기 위한 도구입니다. 사후에 심사팀이 와서 상병을 바꿔 달라고 하는 일을 줄이는 것이 목적입니다. 의무기록실·보험심사팀 기준과 심평원 상병마스터(KCD-8)를 바탕으로 동작합니다.

모든 결과는 참고용입니다. 최종 상병은 진료한 의사가 확정합니다.

가장 흔한 사용 흐름

  1. 검색 탭에서 추정진단명이나 약어를 쳐서 코드를 찾는다 → 코드를 클릭하면 복사됨
  2. 어떤 상병이 맞을지 애매하면 추천 탭에 가명화한 기록을 붙여넣고 AI 추천을 받는다
  3. 처방·검사가 많은 환자는 점검 탭에서 빠진 상병이 없는지 확인한다
  4. 심사팀이 수정을 요청하면 요청기록에 적어 둔다 → 반복되면 규칙으로 만든다

탭별 설명

추천 — "기본 템플릿 넣기"로 응급실 기록 템플릿(CC/onset/PMHx/PI/ROS/PEx/Imp/검사결과/-> 최종 코멘트)을 불러와 채우거나, 가명화한 의무기록(CC, PI, 진찰, 검사, 영상, 추정진단)과 처방·검사를 넣으면 AI가 주진단·부진단·r/o 상병을 이유와 함께 제시합니다. 전송 전 6자리 이상 숫자·전화번호·주민번호는 자동으로 가려지며, 실제 전송 내용을 펼쳐 볼 수 있습니다. 결과는 코드표와 병원 규칙으로 다시 검증됩니다. "전체 복사"로 주)/부)/r/o 형식을 한 번에 복사합니다. 설정 탭에 API 키가 있어야 동작합니다.
검색 — 추정진단명, 응급실 약어(AGE, LBP, ICH…), 한글, 영문, 코드 앞자리 어느 것으로든 찾습니다. 코드 클릭 = 복사. 빨간 표시는 사용불가·불완전코드(청구 거절), 노란 표시는 주상병 지양. "메모"로 "심사팀 선호" 같은 병원 고유 정보를 남길 수 있습니다. 검색창이 비어 있으면 최근 복사한 코드가 보입니다.
점검 — 약·검사·처치와 입력한 상병코드를 적으면 병원 규칙에 비춰 빠진 상병(예: Gaster → K219 없음), 쓰면 안 되는 코드(예: R53), 기록 보완(예: suture 시 cm 기재)을 알려 줍니다. AI 없이 즉시 동작합니다.
기준 — 의무기록실 안내문 원문. 읽기 전용입니다.
요청기록 — 심사팀이 상병 수정을 요청할 때마다 상황·원래 코드·요청 코드·사유를 적습니다. 환자 식별정보는 적지 마세요. "규칙화"를 누르면 규칙 입력 칸에 자동으로 채워집니다.
규칙 — 점검·추천이 사용하는 병원 규칙 목록. 종류는 세 가지: 처방→필요 상병, 코드→사용불가·교체, 기록 작성 유의사항. 조건은 쉼표로 여러 개(모두 만족), 같은 뜻은 |로 묶습니다(예: gaster|가스터). 여기 넣은 규칙은 AI 추천에도 자동 반영됩니다.
분석 — 요청기록이 쌓이면 반복 패턴, 자주 나오는 상황, 월별 건수를 보여 줍니다. 두 번 이상 반복됐는데 규칙이 없으면 "규칙화 권장"이 표시됩니다.
설정 — API 키·모델·연결 테스트, 코드표 상태, 규칙·기록 백업(내보내기/가져오기), 기본 규칙 초기화.

"삭감 안 되는 상병"인지 어떻게 판단하나

삭감 여부를 100% 알려 주는 공식 자료는 없습니다. 이 앱은 세 겹으로 확인하고, 추천 결과의 각 상병 아래에 그 결과를 태그로 보여 줍니다.

  1. 코드표 — 심평원 상병마스터 속성. 불완전코드(세분류가 있는 상위코드)와 주상병불가 코드는 확실히 거절되므로 여기서 걸러집니다.
  2. 병원규칙 — 의무기록실·심사팀이 알려 준 동신병원 기준(R53 불가, Qupron+A099 불가 등). 규칙 탭에서 늘려 갑니다.
  3. 급여기준 — 처방·검사별 급여 인정 상병(고시)은 앱에 들어 있지 않아 "미확인"으로 표시됩니다. 심사팀 요청을 요청기록에 적고 규칙으로 바꿀수록 이 빈칸이 채워집니다. 코드에 메모를 달아 두면 메모가 대신 표시됩니다.

즉, 코드표 ✔ + 병원규칙 ✔이면 "알려진 삭감 사유는 없음"이지 "삭감 안 됨 보장"은 아닙니다.

알아 둘 점

  • 규칙·요청기록·메모·API 키는 이 브라우저에만 저장됩니다. 다른 PC와 공유되지 않으므로, 옮기려면 설정 탭의 내보내기 텍스트를 복사해 그쪽에서 가져오기 하세요.
  • 추천 탭에는 반드시 가명화한 기록만 넣습니다. 이름·등록번호·생년월일·연락처를 지우고 붙여넣으세요.
  • 코드 옆 태그 뜻: 불완전코드 세분류가 있는 상위코드라 청구 불가 · 사용불가 병원 규칙상 불가 · 주상병불가 부진단으로만 · 지양 가능하면 다른 진단으로
